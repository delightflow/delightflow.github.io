# 딜라이트플로우 메인 랜딩 개편 계획 (2026-11-09)

## 무엇을, 왜
대표 요청으로 자사 랜딩 4곳을 모션·섹션 기준으로 개편한다. 이 저장소는 딜라이트플로우 법인 홈페이지
(정적 HTML + style.css, GitHub Pages)이며, 옛 블로그는 `_archive/` 등으로 밀려나 있고 메인은 회사 소개 형식이다.
따라서 블로그 성격 유지가 아니라 회사 소개 랜딩으로 개편한다. `/work/`, `/intro/` 는 건드리지 않는다.

## 범위
1. 히어로 인터랙션 — 바닐라 JS(rAF + CSS 변수). 커서 스포트라이트, 카드 3D 틸트, 서비스 칩 깊이 패럴랙스,
   스크롤 진행도에 따른 배경 영상 확대·카피 페이드. `prefers-reduced-motion` 이면 전부 끄고 배경 영상 정지.
   외부 CDN 추가 없음(기존 GSAP 1개 유지).
2. 회사 소개 모션 영상 v2 — `tools/intro-video/` 의 HTML 프레임을 Playwright(Python)로 캡처, ffmpeg 로
   MP4(H.264)+WebM(VP9)+poster 인코딩. 1280x720, 30fps, 약 30초, 5MB 이하 목표. 페이지에서는 IntersectionObserver 로 지연 로드.
3. 섹션 재설계 — 히어로 → 회사 소개(+영상) → 문제/비전 → 서비스(4개 카드, 실제 URL) → 근거/신뢰 → 연락/CTA.
   숫자·주장은 저장소(`work/`) 또는 각 서비스 사이트에 공개된 문구만 쓰고 출처를 남긴다.

## 검증
- `tools/check_landing.py`: 로컬 정적 서버에서 데스크톱/375px 로드, 콘솔 오류 0, 가로 스크롤 없음, 서비스 링크, 영상 지연 로드·재생 확인.
- 스크린샷(데스크톱·375px) 확인, Chrome 에서 WebM/MP4 실제 디코드 확인.
