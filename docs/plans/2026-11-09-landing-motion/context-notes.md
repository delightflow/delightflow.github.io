## 결정
- 사업영역 섹션은 문제/비전 섹션에 흡수. 다른 페이지 nav 의 `/#business` 가 깨지지 않게 문제/비전 섹션 id 를 `business` 로 둔다.
- 히어로 배경 영상(media/hero.mp4, 10MB)은 유지. reduced-motion 이면 정지.
- 영상: 1280x720·30fps·30초. 장면 = 워드마크(0~5s) → 비전·검색→진단→초안→출원(5~10s) → 서비스 4개 카드(10~24s) → 'AI가 처리하고, 변리사가 책임집니다' + 연락처(24~30s).
  HyperFrames 대신 render(t) 결정적 HTML + Playwright(Python) 캡처를 택했다(설치 없이 재현 가능, 타이밍 완전 제어).
  WebM 디코드 오류 사례 때문에 ffmpeg 에서 bt709·limited(tv) 범위를 명시. 결과 MP4 1.9MB, WebM 0.94MB, poster 50KB.
- 기존 media/hero.mp4(10MB, preload=auto)는 손대지 않았다. LCP 측면에서 줄일 여지가 있어 보고에 남긴다.
- 기존 Products 섹션의 '전체 12개 프로덕트 보기' 버튼이 흰 배경에 흰 테두리(.button.secondary)라 거의 안 보였다 → .button.outline 추가.
- 근거 섹션의 '대표 전승열 변리사(54기)' 는 법인 정보의 대표 이름과 패튼위드 Lead Attorney 이름이 같다는 점에 기댄 문구 → 사용자 확인 필요.
- 데스크톱(900px 높이)에서는 소개 영상이 첫 화면 바로 아래라 로드 직후 소스를 붙인다(rootMargin 300px). 모바일에서는 스크롤 전까지 로드하지 않음을 검증.
